# Windows 桌面 UI/UX 规范

开发或审查界面改动时逐项执行本清单；未通过项在交付说明中显式列出。

## 1. 高 DPI

- [ ] 声明 Per-Monitor V2 感知（Electron：`highDpiSupport`；WPF/WinForms：app.manifest 的 dpiAwareness；Qt 6 默认支持）。
- [ ] 在 100%/125%/150%/200% 缩放下实测，无模糊、错位、溢出。
- [ ] 图标提供多尺寸（16/24/32/48/256）或矢量（.ico 多帧 / SVG）；WPF 用矢量几何。

## 2. 主题

- [ ] 跟随系统深浅主题（Win32 `AppsUseLightTheme`；WPF 用 `ThemeDictionaries`；Qt 用 QPalette/QSS 双套）。
- [ ] 所有颜色走主题 token，无硬编码色值；深色下对比度达标（正文 ≥ 4.5:1，大文本 ≥ 3:1）。
- [ ] 高对比度模式可用（系统辅助功能开启后文字仍可读）。

## 3. 键盘与无障碍

- [ ] 全部功能可纯键盘完成：Tab 顺序合理、焦点可见、常用操作有快捷键。
- [ ] 控件有可访问名称（AutomationProperties / aria-label / QAccessible），屏幕阅读器（讲述人/NVDA）可朗读。
- [ ] 不只用颜色表达状态（配合图标/文本）。

## 4. 输入法

- [ ] 中文/日文输入在文本框、搜索框、表格编辑中正常（候选窗位置正确、上屏不乱码）。
- [ ] 快捷键不与输入法热键冲突（避免裸 Ctrl+Shift 等全局抢占）。

## 5. 窗口与系统集成

- [ ] 最小化/最大化/多显示器恢复位置正确；记住上次窗口几何。
- [ ] 任务栏缩略图/跳转列表（Jump List）按需提供。
- [ ] 通知遵循系统通知中心；托盘图标提供上下文菜单与"退出"入口。
- [ ] 关闭行为明确：主窗口关闭 = 最小化到托盘还是退出，遵循平台惯例。

## 6. 启动与流畅性

- [ ] 启动白屏/闪屏控制在合理范围；启动路径无同步阻塞主线程。
- [ ] 长操作异步执行并显示进度；UI 线程不阻塞（>50ms 的工作移出 UI 线程）。
- [ ] 首次渲染前的窗口背景与主题一致，避免闪白/闪黑。

## 7. 错误与文案

- [ ] 错误信息可行动（发生了什么 + 怎么解决），不用原始堆栈面对用户。
- [ ] 破坏性操作有确认与撤销路径；文案统一中文风格，术语一致。
