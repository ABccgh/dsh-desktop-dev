安装

复制到 DSH 用户预设目录后，新建会话时选择「桌面开发团队」：

$dst = Join-Path ($env:DSH_HOME ?? (Join-Path $HOME '.dsh')) '.agent-presets\desktop-dev'
New-Item -ItemType Directory -Path $dst -Force | Out-Null
Copy-Item -Recurse -Force .\* $dst
